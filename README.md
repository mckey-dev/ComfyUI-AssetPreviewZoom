# ComfyUI Asset Preview Zoom

Updated: 2026-09-03

## 概要

ComfyUI のアセットプレビュー（ライトボックス）で、画像のズームとパン操作を追加するフロントエンド拡張です。ノードは追加しません。

## 機能

- マウスホイールで拡大・縮小する（1x〜10x）
- 1x はプレビュー欄に収めた全体表示。欄より大きい画像は縮小して収める
- カーソル位置を中心にズームする
- ドラッグで画像をパンする
- ダブルクリックで拡大率と位置をリセットする

## インストール

`custom_nodes` にこのフォルダ `ComfyUI-AssetPreviewZoom` を置き、ComfyUI を再起動してください。

## 使用方法

1. ComfyUI を起動する
2. アセットブラウザなどで画像プレビューを開く
3. ホイールでズーム、ドラッグでパン、ダブルクリックでリセットする
